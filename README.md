# Games by sny0

Browser game builds for GitHub Pages.

## Retro — こちら、電話交換局

**[ブラウザで遊ぶ](https://sny0.com/games/retro/)**

電話交換手になって、町の声をつなぐ180秒のゲームです。PCのマウスで操作します。
コードの両端を発信者と接続先へドラッグし、用件が伝わるまでつないでください。
Escで一時停止、右上の「全画面」で町と文字を大きく表示できます。
建物の絵を目印に接続し、火事・消火・配達など、電話と連動する町の様子を見守ってください。

This repository contains playable Web builds. Unity project sources are maintained separately.
Build metadata and file checksums: `retro/build-info.json`.
Third-party notices: `retro/ThirdPartyNotices.txt`.

Pages publishes the `main` branch root. The user site supplies the custom domain,
so this repository does not set a separate CNAME. Game files are served from `retro/`.
